# 🛒 PRINCE ONLINE SHOP

PRINCE ONLINE SHOP is a responsive e-commerce website designed for online shopping.

## 🌐 Website

Live website:

https://alinda666.github.io/prince/

## ✨ Features

- 🛍️ Product listing
- 🛒 Add to Cart
- ➕ Product quantity management
- 💰 Automatic cart total
- 🔥 Flash Sale section
- ⏳ Countdown timer
- 📱 Mobile-friendly design
- 💬 WhatsApp ordering
- 👤 Customer information form
- 💳 Multiple payment methods
- 📍 Delivery address
- 📧 Customer email
- 📞 Customer phone number
