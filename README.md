# 🛍️ PRINCE ONLINE SHOP

A modern, responsive e-commerce website for **PRINCE ONLINE SHOP**, designed to provide customers with a simple and attractive online shopping experience.

## 🌐 Live Website

**PRINCE ONLINE SHOP:**  
https://alinda666.github.io/prince/

---

## 📌 About the Project

PRINCE ONLINE SHOP is a responsive online shopping website built with HTML, CSS, and JavaScript.

The website allows customers to:

- 🛍️ Browse products
- 🔥 View flash sales
- 💰 See discounted prices
- 🛒 Add products to cart
- ❤️ Save favorite products
- 🔎 Search for products
- 📱 Use the website on mobile devices
- 💳 Proceed to checkout
- 📲 Contact the shop through WhatsApp

---

## ✨ Main Features

### 🏠 Homepage

The homepage includes:

- Free shipping announcement
- PRINCE ONLINE SHOP logo
- Search bar
- Navigation
- Shopping cart
- Account section
- Promotional hero section
- Flash sale
- Featured products
- New arrivals

### 🔥 Flash Sale

Customers can see special offers such as:

**UP TO 80% OFF**

Promotional buttons include:

- Shop Now
- Today's Deals

### 🛒 Shopping Cart

Customers can:

- Add products
- View cart items
- Change quantities
- Remove products
- See the total price

### 💳 Checkout

The checkout page allows customers to provide:

- Full name
- Phone number
- Email
- Delivery information
- Payment method

### 📱 Responsive Design

The website adapts to:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile phone

The responsive layout changes the navigation, product grid, buttons, banners, and hero section depending on screen size.
